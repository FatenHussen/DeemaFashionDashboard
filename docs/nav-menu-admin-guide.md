# دليل إدارة شريط التنقّل (Navigation Menu) من الداشبورد

شرح لشاشة **شريط التنقّل** التي تتحكّم بالشريط العلوي في المتجر (الفئات الرئيسية، الماركات، كل المتاجر، سلالي، النقاط، المساعدة، باقات الاشتراك…) — إضافة/تعديل/حذف/ترتيب/تفعيل بدون أي كود.

> **قبل البدء (مرة واحدة على السيرفر):**
>
> ```bash
> php artisan migrate
> php artisan db:seed --class=RolePermissionSeeder   # يضيف صلاحيات navmenuitem.*
> php artisan db:seed --class=NavMenuSeeder          # يزرع عناصر الشريط الافتراضية (آمن للتكرار)
> ```
>
> على الـ installs الجديدة يشغّلهما `DatabaseSeeder` تلقائيًا.

---

## 1. من وين أدخل؟

من القائمة الجانبية: **الأقسام والصفحات ← شريط التنقّل** (المسار: `/sections/nav-menu-items`).

تظهر الشاشة عناصر الشريط **مرتّبة حسب `order`** كما يراها العميل، مع:

- عمود **الترتيب** ورقم كل عنصر.
- عمود **النوع** (شاشة ثابتة / فئة / ماركة / صفحة / رابط خارجي) بلون مميّز لكل نوع.
- عمود **الوجهة** باسم مفهوم (اسم الشاشة، اسم الفئة/الماركة، عنوان الصفحة، أو الرابط نفسه).
- **مفتاح إظهار/إخفاء** داخل كل صف — يعمل مباشرة بدون فتح النموذج.
- زر **إعادة الترتيب** أعلى الجدول (سحب وإفلات).
- بحث + فلاتر (النوع، الحالة) من الشريط الجانبي.

الصلاحيات المطلوبة: `navmenuitem.view` للعرض، و`navmenuitem.create` / `navmenuitem.update` / `navmenuitem.delete` للعمليات.

> **لو الشاشة لا تظهر في القائمة الجانبية:** القائمة تُخفي أي عنصر لا يملك المستخدم صلاحيته حرفيًا (لا يوجد استثناء للسوبر أدمن في الواجهة). شغّل `php artisan db:seed --class=RolePermissionSeeder` ثم أعد تسجيل الدخول ليصل التوكن بالصلاحيات الجديدة.
>
> إلى أن يحدث ذلك، يعمل [permissions.ts](../src/pages/dashboard/nav-menu-items/permissions.ts) كجسر مؤقت: يقبل الصياغات البديلة (`nav_menu_item.*` / `navmenuitems.*`) ويسقط على صلاحيات `pagesection.*`، فيرى الشاشةَ نفسُ من يدير الصفحات والسلايدرات. احذف الإضافات من ذلك الملف بعد تفعيل `navmenuitem.*` على السيرفر.

## 2. إضافة عنصر جديد

1. اضغط **إنشاء** أعلى الجدول.
2. عبّئ **اسم العنصر** بالعربي والإنجليزي (كلاهما مطلوب).
3. اختر **نوع الوجهة**، وسيظهر الحقل المناسب بجانبه:

| النوع | الحقل الذي يظهر | ماذا يفتح |
|-------|------------------|-----------|
| شاشة ثابتة | قائمة الشاشات | إحدى شاشات التطبيق الجاهزة (`route_key`) |
| فئة | منتقي الفئات (شجري مع مسافات بادئة) | صفحة الفئة |
| ماركة | منتقي الماركات | صفحة الماركة |
| صفحة | منتقي صفحات الـ Page Builder | الصفحة المبنيّة |
| رابط خارجي | حقل URL + مفتاح «فتح بتبويب جديد» | رابط خارج التطبيق |

4. (اختياري) ارفع **أيقونة** — صورة حتى 2MB.
5. (اختياري) اضبط **الترتيب** — الأرقام الأصغر تظهر أولًا (أو رتّب لاحقًا بالسحب).
6. اضبط مفتاح **الحالة** (مفعّل افتراضيًا) واضغط **إنشاء**.

### قائمة الشاشات الثابتة

`home` (الرئيسية) · `categories` (الفئات الرئيسية) · `brands` (الماركات) · `shops` (كل المتاجر) · `baskets` (سلالي) · `points` (النقاط والمكافآت) · `help` (المساعدة) · `subscriptions` (باقات الاشتراك).

الأدمن يرى الأسماء المفهومة فقط؛ القيمة التقنية تُرسل للباك إند تلقائيًا.

## 3. تعديل عنصر

اضغط الصف (أو **تعديل** من قائمة الإجراءات). النموذج نفسه يفتح معبّأً.

- **الأيقونة**: اتركها فارغة للإبقاء على الأيقونة الحالية.
- **تغيير النوع**: يُرسل فقط حقل الوجهة الموافق للنوع المختار، فلا تُرسل قيم قديمة من نوع آخر.

## 4. إعادة الترتيب

**إعادة الترتيب** أعلى الجدول ← اسحب العناصر ← **حفظ**. تُرسل الترتيبات النهائية دفعة واحدة إلى
`POST /api/admin/nav-menu-items/reorder` بالشكل `{ "ordered_ids": [3, 1, 5, 2, 4] }`.

## 5. الإظهار والإخفاء

المفتاح داخل الصف يرسل تعديلًا جزئيًا (`PATCH` بحقل `is_active` وحده) — العنصر يبقى محفوظًا لكنه يختفي من
`GET /api/user/nav-menu` الذي يرجّع **المفعّلة فقط**.

## 6. المسارات المستخدمة

| Method | Endpoint | الاستخدام في الشاشة |
|--------|----------|---------------------|
| GET | `/api/admin/nav-menu-items` | الجدول (يُجلب كاملًا؛ البحث والفلاتر محليًا) |
| POST | `/api/admin/nav-menu-items` | إنشاء (`multipart/form-data`) |
| GET | `/api/admin/nav-menu-items/{id}` | تعبئة نموذج التعديل |
| POST + `_method=PUT` | `/api/admin/nav-menu-items/{id}` | تعديل (`multipart/form-data` لدعم الأيقونة) |
| PATCH | `/api/admin/nav-menu-items/{id}` | مفتاح الإظهار/الإخفاء داخل الجدول |
| DELETE | `/api/admin/nav-menu-items/{id}` | حذف |
| POST | `/api/admin/nav-menu-items/reorder` | حفظ ترتيب السحب والإفلات |
